## Project Description

**Human → Meow Translator** is a fun and intentionally useless web application that converts normal human sentences into funny cat-language responses. 🐱

The application uses simple JavaScript keyword-based logic to generate suitable cat responses along with different cat moods, GIF animations, and real meow sounds.

Because humans don't understand cats...

**We decided to make cats understand humans.** 🐾

## The Problem (that doesn't exist)

Cats have been communicating with humans for thousands of years.

They meow.  
They purr.  
They hiss.  
They stare at us.

And somehow, humans still have absolutely no idea what they're saying. 😭

So we decided to solve the most important problem that nobody asked us to solve:

> **"What if my cat understands me, but I don't understand what it's saying?"** 🐱

## The Solution (that nobody asked for)

Introducing the **Human → Meow Translator**! 😺

The user enters a normal human sentence, and the application checks for keywords and converts the sentence into a funny cat response.

For example:

**Human:**
> I am hungry

**Cat:**
> MEEEOOW! MROW MROW! MEOW! 🐱🍗

The application also displays a suitable cat mood, GIF animation, and plays a real cat meow sound.

Because every human deserves to know what their cat is thinking. 🐾
