### Project Description

**Human → Meow Translator** is a fun and intentionally useless web application that converts normal human sentences into funny cat-language responses. 🐱

The application uses simple JavaScript-based keyword detection to understand what humans are saying and generates a suitable cat response along with different cat moods, animations, and real meow sounds.

### The Problem (that doesn't exist)

Humans and cats have been trying to understand each other for centuries.

Cats clearly communicate through meows, but unfortunately, humans have no idea what those meows actually mean.

So we decided to solve the completely unnecessary problem:

> **"What if my cat understands me, but I don't understand what it's saying back?"** 🐾

### The Solution (that nobody asked for)

We created the **Human → Meow Translator**.

Simply enter a sentence in human language and let our highly questionable translation engine convert it into cat language. 😺

For example:

**Human:**
> I am hungry

**Cat:**
> MEEEOOW! MROW MROW! MEOW! 🐱

The application also selects a suitable cat mood, displays a cat animation, and plays a real cat meow sound.

Because apparently, this is the communication technology humanity needed. 🐾
